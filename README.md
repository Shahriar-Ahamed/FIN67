# Money Brain Dashboard (Starter)

FinTech Club | FinTech Innovation Series

A starter Streamlit app for the club project: an AI-powered personal finance dashboard. All data is fake.


## Run it on your own computer (recommended)

1. Install Python 3.11 or 3.12 from python.org.
2. In a terminal inside this folder, run:
   - Windows: `python -m pip install -r requirements.txt` then `python -m streamlit run app.py`
   - Mac: `python3 -m pip install -r requirements.txt` then `python3 -m streamlit run app.py`
3. Open http://localhost:8501 if the browser does not open by itself.

## Run it in GitHub Codespaces 

1. Click **Code**, open the **Codespaces** tab, then **Create codespace on main**.
2. In the terminal, run: `streamlit run app.py`
3. Click **Open in Browser** when the pop-up appears.


## What is in this project

- `app.py`: the dashboard. Look for the lines marked `TEAM TODO`.
- `requirements.txt`: the Python packages the app needs.
- `.gitignore`: tells Git which files never to upload (like secrets).
- `.devcontainer/`: sets up Codespaces automatically.
